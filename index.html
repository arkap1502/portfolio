FEATURED Cybersecurity · Password Security

Altron Password Inspector

A browser-based password generator and strength checker designed with a futuristic cybersecurity HUD interface.

  • Secure generation via crypto.getRandomValues()
  • Adjustable length, character sets & punctuation
  • Visibility toggle, copy-to-clipboard & clear
  • Live strength checking with animated HUD
  • Fully client-side — no data leaves the browser
JavaScriptHTMLCSSWeb Crypto API

Passwords are generated using crypto.getRandomValues() rather than Math.random(), since the former is cryptographically secure and unsuitable-for-security pitfalls of pseudo-random generators are avoided. Strength scoring checks for lowercase, uppercase, digit, and punctuation character classes plus a 15+ character length threshold.

Web Security · Phishing Detection

URL Threat Scanner

A browser-based URL threat analysis tool that evaluates suspicious URL patterns and produces a risk score.

LOW RISKMEDIUM RISKHIGH RISK
  • Risk scoring from 0–100
  • Suspicious IP & TLD detection
  • Brand misspelling & phishing keyword detection
  • Per-finding explanations with a clear verdict
JavaScriptHTMLCSS
⚠ Analyzes URL structure only — it does not visit the site, query DNS, or check external blocklists.

Entirely client-side pattern analysis: the scanner inspects the URL string for structural red flags (raw IPs in place of a domain, uncommon TLDs, lookalike brand spelling, and common phishing keywords) and combines them into a 0–100 score with a plain-language verdict.

Cybersecurity · Phishing Awareness

Phish·AI

A full-stack phishing-awareness simulator that lets users practice spotting phishing scenarios, track attempts, and view leaderboard stats.

  • Registration, login/logout & session management
  • Hashed password storage (Werkzeug security)
  • Phishing scenarios with attempt tracking
  • Accuracy calculation & leaderboard
  • Protected API routes
PythonFlaskFlask-SQLAlchemy SQLiteHTML/CSS/JSWerkzeug

Built as a security-training dashboard: user credentials are hashed rather than stored in plaintext, sessions gate access to scenario and leaderboard routes, and each attempt is logged to compute a per-user accuracy score shown on a shared leaderboard.
