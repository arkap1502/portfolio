# Arka Patra — Portfolio

A static portfolio for Arka Patra, a cyber security student and security-focused developer from West Bengal, India. Built with HTML, CSS and JavaScript — no frameworks or build step.

## Pages

- [Home](index.html) — landing page
- [Dashboard](dashboard.html) — portfolio home
- [Projects](projects.html) — security tools and experiments
- [About](about.html) — profile, education and experience
- [Certificates](certificates.html) — internship and course certificates
- [Contact](contact.html) — contact details and message form

## Run locally

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.
