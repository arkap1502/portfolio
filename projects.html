FEATURED Cybersecurity · Password Security

Altron Password Inspector

Browser-based password generator and strength checker with HUD interface.

  • Secure generation via crypto.getRandomValues()
  • Adjustable length, character sets & punctuation
  • Live strength checking with animated HUD
JavaScriptHTMLCSSWeb Crypto API

Passwords are generated using crypto.getRandomValues() rather than Math.random(), since the former is cryptographically secure and unsuitable-for-security pitfalls of pseudo-random generators are avoided. Strength scoring checks for lowercase, uppercase, digit, and punctuation character classes plus a 15+ character length threshold.

FEATURED Cybersecurity · Prompt Injection Detection

Hidden-Prompt Scanner for Documents

Scans PDF, DOCX, TXT, MD & HTML for hidden prompt-injection attacks targeting LLMs.

  • Detects white-on-white, zero-size, transparent & off-page hidden text
  • Flags injection phrases + metadata, comments & annotation scan
  • LOW / MEDIUM / HIGH risk score with CLI + JSON report & web UI
PythonFlaskPyPDF2python-docxBeautifulSoup

Extracts visible text plus layout signals (color, font size, opacity, position) to flag color ≈ background, size ≤ 1.5pt, opacity == 0 and off-page content, including zero-width chars (U+200B/C/D, U+FEFF); checks PDF metadata, DOCX properties, comments & footnotes, then regex-matches injection phrases like ignore previous instructions into a combined risk score — fully local via scanner.py CLI and Flask web UI.
